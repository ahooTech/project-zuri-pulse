# ZuriMart Tagging Policy

**Project:** PROJECT ZURI PULSE  
**Phase:** 2  
**Step:** 3  
**Status:** ACTIVE

## Required Tags

Every Terraform-managed resource must include the following tags or labels:

| Tag Key | Allowed Values | Purpose |
|---|---|---|
| Project | `zuri-platform` | Identifies the platform project |
| Environment | `dev`, `staging`, `production`, `bootstrap`, `dr` | Identifies lifecycle stage |
| Owner | `devops`, `platform`, `security`, `data`, `app-team` | Identifies responsible owner |
| CostCenter | `retail-online` | Enables FinOps cost allocation |
| Application | `zurishop` | Identifies business application |
| ManagedBy | `terraform`, `manual`, `pipeline` | Identifies provisioning method |

## Standard Production Example

```hcl
tags = {
  Project     = "zuri-platform"
  Environment = "production"
  Owner       = "devops"
  CostCenter  = "retail-online"
  Application = "zurishop"
  ManagedBy   = "terraform"
}

```

## GCP Labels

GCP labels must be lowercase.
Use the global tags module output:


labels = module.tags.gcp_labels


## Enforcement

Tagging is enforced through:

The global tags module.
Pull request review.
Future automated policy checks.
Future cloud policy controls.



## Exceptions

Exceptions must be documented in the pull request and approved by the infrastructure owner.
