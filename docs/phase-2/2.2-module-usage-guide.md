## Global Tags Module

Use the global tags module in every environment root.

Example from an environment networking root:

```hcl
module "tags" {
  source      = "../../../modules/global/tags"
  environment = "dev"
}


```

# For AWS or Azure resources:

tags = module.tags.tags


# For GCP resources:


labels = module.tags.gcp_labels




# Global Naming Module

Use the global naming module to generate standardized resource names.
Example:

Example:

module "vpc_name" {
  source        = "../../../modules/global/naming"
  environment   = "dev"
  cloud         = "aws"
  layer         = "networking"
  resource_type = "vpc"
}


Result:


zuri-platform-dev-aws-net-vpc



# Future Module Pattern

Every future resource module should follow this pattern:



module "tags" {
  source      = "../../../modules/global/tags"
  environment = var.environment
}

module "example_name" {
  source        = "../../../modules/global/naming"
  environment   = var.environment
  cloud         = "aws"
  layer         = "networking"
  resource_type = "vpc"
}


Then use:

name = module.example_name.name
tags = module.tags.tags
